## 🎯 Описание проекта

Savor - это полнофункциональная система бронирования столов для ресторана, разработанная на Django. Система предоставляет удобный интерфейс для клиентов для бронирования столов и мощную панель администратора для управления бронированиями, столами и настройками ресторана.

## ✨ Функциональность

### Для клиентов:
- 📅 **Бронирование столов** - выбор даты, времени и количества гостей
- 🎯 **Интерактивная схема зала** - визуальный выбор столов
- 👤 **Личный кабинет** - просмотр и управление бронированиями
- ✏️ **Редактирование бронирований** - изменение даты, времени, количества гостей
- ❌ **Отмена бронирований** - возможность отменить бронь
- 📧 **Форма обратной связи** - отправка сообщений администрации
- 📱 **Адаптивный дизайн** - работает на всех устройствах

### Для администраторов:
- 🔧 **Панель администратора** - полное управление системой
- 📊 **Управление бронированиями** - просмотр, редактирование, отмена
- 🪑 **Управление столами** - добавление, редактирование, деактивация
- ⚙️ **Настройки системы** - время работы, продолжительность брони
- 📨 **Сообщения обратной связи** - просмотр и управление
- 👥 **Управление пользователями** - блокировка, роли
- 📧 **Email уведомления** - автоматические уведомления о бронированиях

## 🚀 Установка и настройка

### Предварительные требования:
- Python 3.8+
- PostgreSQL 12+
- Redis (опционально)
- Git

### 1. Клонирование репозитория:
```bash
git clone <repository-url>
cd Table_Reservation
```

### 2. Создание виртуального окружения:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows
```

### 3. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения:
Создайте файл `.env` в корне проекта и добавьте необходимые данные по примеру `.env.example`

### 5. Настройка базы данных:
```bash
# Создание базы данных PostgreSQL
createdb savor_db

# Применение миграций
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser
```

### 6. Сбор статических файлов:
```bash
python manage.py collectstatic
```

## 🏃‍♂️ Запуск проекта

### Разработка:
```bash
# Активация виртуального окружения
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows

# Запуск сервера разработки
python manage.py runserver
```

```bash

# Запуск с Gunicorn

# Или с uWSGI
uwsgi --ini uwsgi.ini
```

## 📖 Использование

### Для клиентов:
1. **Регистрация/Вход** - создайте аккаунт или войдите в систему
2. **Выбор даты и времени** - укажите желаемую дату и время бронирования
3. **Выбор стола** - на интерактивной схеме выберите подходящий стол
4. **Заполнение формы** - введите контактные данные и количество гостей
5. **Подтверждение** - получите подтверждение бронирования на email

### Для администраторов:
1. **Вход в админку** - перейдите на `/admin/` и войдите с правами суперпользователя
2. **Управление бронированиями** - просматривайте, редактируйте и отменяйте брони
3. **Настройка столов** - добавляйте новые столы и изменяйте их параметры
4. **Системные настройки** - настройте время работы ресторана и продолжительность брони
5. **Сообщения** - отвечайте на сообщения обратной связи

## 🔌 API Endpoints

### Бронирования:
- `GET /api/tables/` - получение списка столов
- `POST /api/book-table/` - создание бронирования
- `GET /api/reservation/{id}/` - получение данных бронирования
- `POST /api/reservation/{id}/edit/` - редактирование бронирования
- `POST /api/reservation/{id}/cancel/` - отмена бронирования

### Система:
- `GET /api/settings/` - получение настроек системы
- `POST /api/profile/delete/` - удаление профиля пользователя

## 🐛 Устранение неполадок

### Частые проблемы:

1. **Ошибка подключения к базе данных:**
   - Проверьте настройки в `.env`
   - Убедитесь, что PostgreSQL запущен
   - Проверьте права доступа пользователя

2. **Статические файлы не загружаются:**
   - Выполните `python manage.py collectstatic`
   - Проверьте настройки `STATIC_URL` и `STATIC_ROOT`

3. **Email не отправляется:**
   - Проверьте настройки SMTP в `.env`
   - Убедитесь, что `fail_silently=True` в настройках

4. **Миграции не применяются:**
   - Удалите все файлы в `migrations/` (кроме `__init__.py`)
   - Выполните `python manage.py makemigrations`
   - Затем `python manage.py migrate`
